# Contenu Local Niger

Build a polished, professional, French-first web app MVP called:

"Plateforme nationale des acteurs et des opportunités du contenu local pétrolier"

Context:

This is a demo MVP for a ministry-level client in Niger. The platform is intended for the Ministry of Petroleum to register, structure, and manage suppliers, service providers, and subcontractors linked to the petroleum sector, while also publishing sector opportunities and helping internal teams monitor local content participation.

Main goal:

Create a realistic, high-value MVP that looks serious enough for a ministry demo and commercial pitch. The app must feel like a real government-backed portal, not a startup toy. It must be elegant, trustworthy, structured, clear, and easy to navigate on desktop and mobile.

Product positioning:

This platform is NOT a generic procurement portal. It is a sectoral portal for:

1. registering and qualifying national companies,

2. publishing sector opportunities,

3. providing a ministry dashboard for monitoring local content actors.

Target users:

1. Public visitors

2. Companies / suppliers / subcontractors

3. Ministry reviewers / internal officers

4. Ministry administrators / decision-makers

Language:

Primary language must be French.

Structure the copy in clear, formal, institutional French.

Make the UI ready for future multilingual expansion, but only implement French now.

Brand style:

Use a modern, institutional, premium government-service look.

Style should communicate:

- trust

- clarity

- seriousness

- transparency

- digital modernization

Visual direction:

- clean layout

- generous spacing

- premium cards

- professional tables

- calm and elegant dashboard

- subtle modern animations

- strong mobile responsiveness

- neutral palette with refined accents inspired by public institutions

- avoid flashy startup style

- avoid playful illustrations

- use clean icons where useful

Create a full MVP with these main areas:
